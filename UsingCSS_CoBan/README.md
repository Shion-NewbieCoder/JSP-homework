# Bài thực hành: Sử dụng các thuộc tính của CSS

**Mục tiêu:** Luyện tập khai báo CSS trong thẻ `<style>` để thay đổi thuộc tính của HTML.

## Hướng dẫn chạy

Mở `index.html` bằng WebStorm, VS Code hoặc trình duyệt (nháy đúp file để mở). Không cần cài thư viện, server hoặc cơ sở dữ liệu.

## Đối chiếu các bước của đề

1. Tạo tệp `index.html`, chứa tiêu đề `<h1>` và đoạn văn `<p>`.
2. Áp dụng `color`, `font-family`, `font-size`: tiêu đề xanh, Tahoma, 200%; đoạn văn đỏ, Arial, 120%.
3. Thêm `border: 1px solid grey;` cho các đoạn văn.
4. Thêm `padding: 10px;` giữa nội dung đoạn văn và viền.
5. Thêm `id="element1"` cho đoạn văn cuối và dùng `#element1 { color: blue; }` để chỉ đổi màu đoạn đó.

**Kết quả:** Có 1 tiêu đề màu xanh và 4 đoạn văn có viền, phần đệm; 3 đoạn đầu chữ đỏ, đoạn cuối chữ xanh. Thuộc tính viền và padding vẫn giữ ở đoạn cuối.
