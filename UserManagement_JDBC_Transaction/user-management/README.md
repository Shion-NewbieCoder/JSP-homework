# User Management — JDBC Transaction

Ứng dụng MVC Java 17 / JSP-JSTL 3.0 / Servlet 6.0 / MySQL 8 (Tomcat 10.1+).

**Nâng cấp bài trước:** CRUD, tìm kiếm `country`, sắp xếp `name`, Stored Procedures tra User khi Edit vẫn giữ nguyên; **tạo User** chuyển từ `insertUserStore` sang `addUserTransaction` để ghi `users` và `user_permission` nguyên tử (atomic).

Xem [README bài nộp ở thư mục trên](../README.md) để thiết lập và kiểm tra.
