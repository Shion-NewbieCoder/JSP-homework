# Product Discount Calculator

Tài liệu đầy đủ (bao gồm mã nguồn để chấm) nằm ở [`../README.md`](../README.md).

Để chạy: `mvn clean package` → triển khai `target/jsp-servlet-product-discount.war` lên Tomcat 10.1+ → mở `http://localhost:8080/jsp-servlet-product-discount/`.

Kiểm thử logic trực tiếp: `scripts/test-windows.bat` hoặc `sh scripts/test-linux-macos.sh`.
