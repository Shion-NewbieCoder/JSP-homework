# User Management — MySQL Stored Procedures

Đây là dự án Maven JSP/Servlet sử dụng MySQL JDBC: CRUD + tìm kiếm quốc gia + sắp xếp theo tên. Hai thao tác `getUserById` và `insertUserStore` dùng `CallableStatement` gọi Stored Procedures.

Xem [README bài nộp](../README.md) để có hướng dẫn MySQL, Maven, Tomcat và mã nguồn phục vụ kiểm tra.
