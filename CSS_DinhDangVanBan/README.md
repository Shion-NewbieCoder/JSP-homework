# Bài thực hành: Định dạng văn bản bằng CSS

## Mục tiêu
Tạo một tài liệu HTML sử dụng CSS để định dạng văn bản, gồm: `font-style`, `text-align`, `font-size`, `text-indent`, `color` và một số thuộc tính hỗ trợ.

## Cách xem
Mở `index.html` trực tiếp trên Chrome, Edge hoặc trình duyệt khác. Không cần máy chủ hoặc thư viện bên ngoài.

## Các thuộc tính đã sử dụng

| Thuộc tính CSS | Vị trí / công dụng |
| --- | --- |
| `font-style: italic` | Dòng chú thích và đoạn chữ in nghiêng |
| `text-align: justify` | Căn đều hai bên nội dung bài viết |
| `text-align: left` | Căn trái tiêu đề và dòng nguồn |
| `font-size: 32px`, `17px`, `13px` | Phân cấp tiêu đề, thân bài, chú thích |
| `text-indent: 40px` | Thụt dòng đầu mỗi đoạn văn |
| `color` | Màu văn bản chính, chú thích và từ khóa nhấn mạnh |
| `font-family`, `font-weight` | Kiểu chữ và độ đậm |
| `line-height` | Giãn dòng giúp dễ đọc |

## Ghi chú
- Code đặt trong thẻ `<style>` của `index.html` để giảng viên/bộ chấm đọc được toàn bộ lời giải từ một file GitHub.
- Ảnh mẫu CodeGym không tải được tại thời điểm chuẩn bị; bài làm tái hiện **kỹ thuật CSS đề yêu cầu**, chưa xác nhận nội dung chữ/chi tiết trình bày giống 100% ảnh minh họa.
- Không cần chỉnh sửa hoặc chạy lại các bài CSS trước.
